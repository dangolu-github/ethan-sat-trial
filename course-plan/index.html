Reading & Writing · Classes 01–14

20-Hour Course Plan

From Class 05, every class has three parts: Grammar, Punctuation, and one Reading unit that ends with Words in Context questions. A few extra questions and words are ready for each class if time allows; whatever is not reached in class becomes part of that class’s homework.

Dates and details may change
01

Three parts every class

Grammar and Punctuation each teach one complete topic with its rules and worked SAT questions. The Reading unit works through real SAT questions of one type and draws the method from them.

02

Words in Context every class

Each Reading unit ends with Words in Context questions, so the method for word choices builds up week by week instead of in one separate class.

03

Extra questions and words if time allows

Each class has a few extra questions and a few words from the class’s theme. What is not reached in class goes into that class’s homework.

Classes 05–11

One unit each

Each class: one Grammar topic, one Punctuation mark, one Reading unit with Words in Context questions at the end. Extra questions and a few words are ready if time allows.

Oct03

Class 05

Verbs · The Semicolon · Evidence from Data

Grammar
Verbs: time and aspect. Past simple, present perfect, past perfect, the progressive, and shifts of tense.
Punctuation
The semicolon: between two complete sentences, with a linking adverb, and in a list.
Reading
Command of Evidence · Quantitative: a line graph, a table and a bar graph connected to the exact claim. Words in Context: fix the logic of the sentence before choosing the word.

Punctuation
The colon, compared with the semicolon.
Reading
Command of Evidence · Textual: findings that support or weaken a claim. Words in Context: a contrast clue.

Grammar
