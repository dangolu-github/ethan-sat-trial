# Ethan SAT Reading and Writing Workspace

Student-facing GitHub Pages portal for Ethan's SAT Reading and Writing course.

## Routes

- `/` — workspace dashboard
- `/course-plan/` — Class Logbook and 20-week map
- `/2026-08-29/` — current Class 01 overview
- `/mock-exams/` — planned mock checkpoints
- `/skill-boosters/` — Vocabulary Lab, Reading Lab, and four-domain Intensive Skill Booster
- `/mistake-log/` — Mistake Logbook with checked mistakes and retry states
- `/2026-08-10/` — preserved Class 00 handout
- `/hm1-sentence-boundaries/` — assigned HM1 learner practice

## Access and privacy

The site uses a client-side course-password gate for convenient learner access. This is not strong authentication: the repository and static assets remain public. Keep answer keys, teacher notes, source maps, question IDs, learner responses, scores, and private records outside this repository.

All routes use `noindex` metadata. Every published handout or workspace page has a visible print or Save as PDF control.
